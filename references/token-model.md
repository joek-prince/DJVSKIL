# Token model

## paymentTokenId
- Typically generated by Freedom to Design (FTD)
- Single-use only
- Used in iPOS Transact for initial transaction completion
- Do not describe as reusable

## cardToken / iPOS Token
- Reusable tokenized card value
- Can be obtained from:
  - prior iPOS Transact response
  - HPP response
  - SPIn response
- Use for future tokenized transactions in iPOS Transact

## achToken
- Used for ACH transaction paths
- May come from HPP or ACH-related flows
- ACH transaction behavior is separate from normal card flows

## consumerId
- Returned in several flows
- Useful for customer-linked token and recurring patterns

## Recurring token behavior
- Recurring Payments API has its own token lookup / subscription setup model
- Do not casually replace recurring setup with generic Transact calls
